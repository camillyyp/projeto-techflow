Sistema de Controle de Vendas
Descrição
Sistema desktop desenvolvido em Python para gerenciamento de clientes, produtos e vendas.

Funcionalidades
Login de usuários
Cadastro de clientes
Cadastro de produtos
Registro de vendas
Persistência dos dados
Estrutura do Projeto
src → arquivos Python do sistema
views → interfaces gráficas (.ui)
utils → conexão e funções auxiliares
data → armazenamento dos dados
Como Executar
Instalar dependências:

pip install -r requirements.txt

Executar o sistema:

python main.py
